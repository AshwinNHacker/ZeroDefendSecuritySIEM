# 🛡️ SOC-X: 2024 Edition

## 🧠 Executive Summary

**SOC-X: 2024 Edition** is a modular Security Operations Center (SOC) framework developed by **Zero Defend Security** to deliver scalable, cost-effective SIEM capabilities for small and mid-sized enterprises.

This initiative leverages open-source technologies to provide real-time threat detection, incident response automation, and compliance-ready reporting. Designed with operational clarity and auditability in mind, SOC-X empowers organizations to adopt enterprise-grade cybersecurity without the overhead of traditional SOC deployments.

---

## 🧩 Core Capabilities

- ✅ Real-time log aggregation and monitoring  
- ✅ File integrity verification across endpoints  
- ✅ USB device control and audit logging  
- ✅ Automated response and blocking mechanisms  
- ✅ Firewall policy integration  
- ✅ Suspicious domain and URL tracking  
- ✅ Threat intelligence feed ingestion  
- ✅ Custom rule sets and alerting logic  
- ✅ Detection of C2 (Command & Control) traffic  
- ✅ Visual dashboards via Wazuh + Kibana  

---

## ⚙️ Technology Stack

| Component         | Purpose                                  |
|------------------|-------------------------------------------|
| **Wazuh**         | SIEM & Host-based IDS                    |
| **Filebeat**      | Lightweight log shipper                  |
| **Elasticsearch** | Log indexing and search engine           |
| **Kibana**        | Visualization and dashboard interface    |
| **Windows/Linux** | Multi-platform endpoint coverage         |
| **Custom Scripts**| Active response via Shell & PowerShell   |
